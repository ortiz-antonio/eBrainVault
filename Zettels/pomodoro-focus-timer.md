## Focus timer
- Funciona sobre un task (Zettel) haciendolo compatible con obsidian, con dos versiones, pomodoro y flowmodoro
### Flowmodoro
- Ideal para quienes manejan su tiempo escribiendo, para no tener interrupciones y llevar control de sus horas

## Ideas tecnicas
### API
- Puedo exponer la api como: /task/{TASK NAME}/{EST}
- Entonces al mandarla llamar te crea un task  y empieza tu ciclo de timer.
- Donde TASK NAME Es el nombre del task y  EST es la estimacion que le diste.
- De esta manera puedo integrar en obsidian, la creacion de task seria bastante rapida, y no solo en obsidian quiza tambien en editores de codigo como visual estudio

### Cliente
	Si puedo integrar un cliente a nivel OS, que envie el texto seleccionado al api de focus, hare una integracion app agnostic
