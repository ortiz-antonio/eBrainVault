# Validation Techique: Mixed Wizard of oz
 No quiero adelanterme como en otros proyectos que trabaje para hacer el producto sin tener respuesta, por lo tanto vamos a encontrar una manera de validar sin tener el producto aun, pero sin enganar a las personas prometiendo algo que no existe aun.
 
Para el copy combinar dos enfoques:
Mostrar la parte que ya esta funcionando para que el usuario entienda, mientras para la nueva caracteristica una simulacion donde el usuario ve la ui de la web, pero el trabajo de programacion no existe aun, solo se entrega un archivo de ejemplo o se hace manualmente, siguiendo la tecnica wizard of oz.

Por ejemplo:
Mostrar namepreview mientras muestro un demo de descarga, con un solo nombre, asi entienden que si se subscriben van a generar ese tipo de productos automaticamente.
