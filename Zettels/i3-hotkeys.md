# i3 hotkeys
- `meta + shift + e` logout
- `meta + w` tabbed windows
- `meta + f` full screen windows
- `meta + shift + ->` Go to the next window
- `meta + d` search apps
- `meta + enter` terminal
## Custom hotkeys
- `ctrl + alt + del` shutdown
