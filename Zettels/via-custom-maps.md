# Mapeos de Teclado (VIA)

## Navegación y Sistema
- [x] `fn2 + p` PrtSC  
- [x] `fn2 + ←` home
- [x] `fn2 + →` end
- [ ]  `fn2 + q` alt + f4

## Control del Mouse
- [x] fn2 + up mouse wheel up
- [x] fn2 + down mouse wheel down
- [x] `fn1 + ARROW_KEYS` move mouse
- [x] `fn1 + enter` left click
- [x] `fn1 + shift` right click

## Macros de Texto
- [x] `fn2  + e` ortiz.antonio@gmail.com
- [x] `fn2  + n` Antonio Ortiz
- [x] `fn2 + p` MAIN_PASSWORD
- [ ] - [ ]  `fn2 + w` WIFI_PASS
