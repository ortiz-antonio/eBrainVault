# C4
Es una metodologia de diagramas, que hace zoom para los diferentes niveles de abstraccion de la app, cada nivel de abstraccion es util para la persona que cumple el rol necesitado para esa abstraccion

## C4 niveles de abstraccion:

### Context / Software system
Es la totalidad del sistema con diferentes containers, se representan otros sistemas o usuarios a la par. 
Ejemplo: [[Zettels/pomodoro-arquitecture-diagram-c4-context|pomodoro-arquitecture-diagram-c4-context]]

### Containers
Son las diferentes apps que forman el sistema, por ejemplo, una web,  backend, base de datos cada uno es un container dentro del sistema, interactuando entre si.
Ejemplo: [[Zettels/pomodoro-arquitecture-diagram-c4-container|pomodoro-arquitecture-diagram-c4-container]]

### Components
Son las diferentes modulos que forman un container.
### Code
Es la implementacion a mas bajo nivel, de un component.
