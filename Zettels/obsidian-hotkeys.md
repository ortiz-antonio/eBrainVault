## Personalizando Obsidian con hotkeys para usarlo solo con teclado

Empece a configar mejor mi obsidian, por que me doy cuenta que ahora sera mi lugar de trabajo, por que primero escribire y definire, antes de empezar a escribir directamente en otros lados: Por escribir directamente me refiero a prompts, busquedas, casi todo es de buscar.


## Tools Hotkeys

- `ctrl + shift + t` Insert template
-  `ctrl + shift + c` Collapse (Toggle left sidebar)
-  `ctrl + shift + d` Insert Date
-  `ctrl + shift + H` Insert Hour
- `ctrl + shift + M` Move to to another folder (useful for archive)
- `ctrl + shift + N` QuickAdd 
- `ctrl + shift + P` Copy Filepath
-  `ctrl + shift + s` Toggle source / live preview mode 
- 

## QuickAdd Templates Hotkeys
- `alt + f` Insert fleeting note template
- `alt + z` Insert permanent note (zettel) template 
- `alt + m` Insert moc note
- `alt + l` Insert Literature note

# Move Lines (for project status)
- `alt + ↑` 
- `alt + ↓`

- Personalizado para agregar nuevas notas al Inbox
