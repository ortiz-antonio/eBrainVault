# Vector resize
A los vectores se les puede hacer un resize simplemente editando su codigo, probablemente pueda hacerlo muy facil si en el boton de download hago un get, con el size indicado, leyendo el vector los params de get.

La idea que se me ocurre es el api entrega el svg segun las medidas requeridas.
- emma/300/200
- emma/150mm/100mm
- emma/
	- Genera default size

## IA
Lo mejor es que la API acepte solo el ancho: emma/150mm y devuelva el alto calculado. Así proteges la Calidad del Producto, que es tu promesa de marca.
